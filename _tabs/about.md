I'm Peter. I investigate intrusions for a living, and I'm going deep on memory forensics: pulling the story out of RAM after someone has tidied up everything else.

I used to write software, and after that I studied how to break it. So I read malware like a code review, and an intrusion like someone else's project plan. (GREM, if you like letters after names.)

**Two tracks here:**

- **Forensics:** what the evidence says. Volatility 3, Windows internals, malware hiding in memory.
- **Analysis:** why smart analysts still get it wrong. Bias, hypotheses, and lessons from intelligence analysts who learned the hard way.

My views, nobody else's.

Spot a mistake? Say so in the comments. Being wrong in public is cheaper than being wrong in an incident report.
